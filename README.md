# EE-551-Behind-the-Curtain-Mechatonix-Face



The Behind The Curtain Mechatonix Face is operated by running the file robot_voice_with_animation.py and speaking into your device's microphone. The file face_graphics.py must be downloaded so that it can be imported by robot_voice_with_animation.py. Below is a list of necessary packages that must be downloaded in correspondence with each of these two files:

For robot_voice_with_animation.py:
Whisper Model download link : https://huggingface.co/openai/whisper-small.en
1. Must have faster_whisper installed
2. Must have piper installed
3. Must have sounddevice installed
4. Must have numpy installed
5. Must have pyttsx3 installed
...

For face_graphics.py:
1. Must have pygame-ce installed
